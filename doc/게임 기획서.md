# 2d 갤러그 게임 기획서

1. 게임 개요
- 게임명: 갤러그 게임
- 장르: 2D 아케이드 슈팅 게임

2. 핵심 게임 시스템

2.1 플레이어

- 화면 하단에서 좌우로 이동할 수 있다
- 스페이스바를 눌러 총알을 발사한다.
- 적이나 적의 총알에 충돌하면 체력이 감소한다
- 체력이 모두 소진되면 게임 오버
- 피격 후 짧은 시간 동안 무적 시간이 생긴다.

2.2 적

- 적은 스테이지에 따라 서로 다른 행동을 한다
- 일반 적: 일정한 간격을 유지하며 좌우로 이동한다.
- 공격형 적: 일정한 간격으로 플레이어를 향해 총알을 발사한다.
- 돌진형 적: 일정한 간격에서 이탈하여 플레이어가 위치한 방향으로 돌진한다.

2.3 점수 및 체력
- 플레이어의 초기 체력은 3으로 시작
- 일반 적 처치 시 100점, 공격형 적 처치시 150점, 돌진형 적 처치시 200점을 획득한다.

3. 조작키

- <-/A 		왼쪽 이동
- ->/D 		오른쪽 이동
- SPACEBAR 	공격
- ENTER	 	시작/재시작
- ESC   	종료

4. 스테이지
- 1 등장 적: 일반 적
    특징:좌우 이동을 통한 기본 조작 학습
- 2 등장 적: 일반 적 + 공격형 적
    특징:적 탄환 회피 추가
- 3 등장 적:일반 적 + 돌진형 적
    특징:돌진 예측 및 회피 추가
- 4 등장 적:3종류 모두
    특징:복합적인 공격 패턴
- 5 등장 적:3종류 모두
    특징:적 수,이동속도,공격 빈도 증가
